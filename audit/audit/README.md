# Audit package

This directory contains the final bilingual audit reports, structured findings, business documentation,
reproduction evidence, and the HackChain interaction diagram.

Only the final reports are included. There are no previous report versions or intermediate audit drafts.

The Solidity contracts under `src/` are the audited source snapshot. The Foundry tests reproduce observed
behaviors; they are not patched contracts and should not be interpreted as remediations.
